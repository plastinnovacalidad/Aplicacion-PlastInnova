One-line: the pill-shaped, uppercase action button — `accent` for the single main CTA on a view, `primary` for everything else.

```jsx
<Button variant="accent" size="lg" iconRight="arrow-right">Cotizar ahora</Button>
```

Variants: `primary` (solid blue), `accent` (red gradient + red shadow, max one per screen), `secondary` (1.5px blue outline), `subtle` (blue-50 fill), `ghost`. Sizes `sm|md|lg`. Press state scales to .97; hover darkens one step.
